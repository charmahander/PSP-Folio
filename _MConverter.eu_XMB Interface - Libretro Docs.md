XMB \(GUI\)

**XMB** was the default user interface for RetroArch, until it was succeeded by Ozone in RetroArch 1.7.6. It is based on Sony's "cross-media bar" GUI, most widely known from the PSP

and PlayStation 3. 

Menu Structure

The top-level menus and playlists are displayed in a single "primary" row, running from left to right. For the selected row item, a submenu column wil appear below it. 

Navigating the menus

XMB is designed for use with a gamepad or keyboard. 

Press left or right to move along the primary row, and press up or down to scrol the column. The selected item in this column is always the first line under the primary row. 

The user can press backspace to go back a step.

Thumbnails

Chat with 

By default, no thumbnails are displayed. Up to 2 can be enabled: The primary thumbnail wil appear on the lower right side of the screen when a Playlist entry is selected. The secondary thumbnail wil appear on the left. Press the spacebar key to view the thumbnails full-screen \(press spacebar again to toggle the view off\). 

Thumbnails can be enabled in Settings> User Interface> Appearance , toggling the Primary Thumbnail and/or Secondary Thumbnail option. Thumbnails can be boxart, a title screen screenshot, or a gameplay screenshot. 

XMB with 'Boxart' thumbnails enabled

Themes

XMB has a number of styles built-in. They can be changed in the Settings > User Interface

> Appearance menu. 

The background color can be changed: Scrol through Color Theme to select a color. 

The animated background "wal paper" can also be changed \( Shader Pipeline \), the default being a PlayStation-style animated ribbon. 

XMB can even show different wal papers depending on the playlist selected: Fol ow

this guide using these files. 

XMB also has a selection of icon sets to choose from \( Icon Theme \).
